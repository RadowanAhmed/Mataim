## 📱 Overview

Mataim is a comprehensive food delivery platform that serves three types of users:

| 👤 **Customers**                 | 🚴 **Drivers**                              | 👨‍🍳 **Restaurants**                   |
| -------------------------------- | ------------------------------------------- | ------------------------------------ |
| Order food from 500+ restaurants | Flexible delivery work with instant payouts | Manage orders and grow your business |
| Real-time order tracking         | Smart route optimization                    | Menu management dashboard            |
| Multiple payment options         | Performance analytics                       | Sales insights and reports           |

## ✨ Key Features

### 🍽️ For Customers

- **Smart Search** - Filter by cuisine, price, ratings, and dietary preferences
- **Live Tracking** - Watch your delivery arrive in real-time on an interactive map
- **Favorites** - Save your go-to restaurants and dishes for quick reordering
- **Schedule Orders** - Order now for delivery later
- **Secure Payments** - Cash, card, or digital wallet options
- **Exclusive Deals** - Daily discounts and special offers
- **Order History** - View past orders and easily reorder favorites

### 🚴 For Drivers

- **Flexible Hours** - Work when you want, as much as you want
- **Instant Payouts** - Get paid daily or weekly
- **Smart Routing** - Optimized delivery routes to save time and fuel
- **Performance Tracking** - Monitor your earnings, ratings, and delivery stats
- **24/7 Support** - Dedicated assistance whenever you need it
- **Safety Features** - Insurance and safety guidelines included

### 👨‍🍳 For Restaurants

- **Intuitive Dashboard** - Manage orders, menu, and analytics in one place
- **Real-time Updates** - Instant notifications for new orders
- **Menu Management** - Update items, prices, and availability instantly
- **Performance Insights** - Track sales, popular items, and customer feedback
- **Driver Network** - Access to professional delivery partners
- **Marketing Tools** - Promotional features to boost visibility and sales

## 🛠️ Tech Stack

| Category             | Technologies                         |
| -------------------- | ------------------------------------ |
| **Frontend**         | React Native with Expo SDK 50        |
| **Navigation**       | Expo Router (file-based routing)     |
| **Backend**          | Supabase (PostgreSQL, Auth, Storage) |
| **State Management** | React Context API                    |
| **Maps**             | React Native Maps with Google Maps   |
| **Payments**         | Cash, Card, Digital Wallet           |
| **Notifications**    | Expo Push Notifications              |
| **Location**         | Expo Location API                    |
| **Images**           | Cloudinary for image uploads         |
| **Animations**       | Lottie for smooth animations         |
| **Fonts**            | Expo Font with custom fonts          |

## 📋 Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)
- Supabase account (free tier works)
- Google Cloud Platform account (for Maps and OAuth)
- Cloudinary account (for image uploads)
